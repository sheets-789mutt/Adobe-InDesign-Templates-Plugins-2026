## What's Included

This suite bundles essential tools for an enhanced InDesign workflow:

*   **Template Manager:** Easily import, categorize, and apply pre-made templates for books, magazines, and brochures.
*   **Plugin Hub:** A central interface to discover and manage third-party extensions for typography and layout automation.
*   **Batch Processing:** Perform batch operations on multiple InDesign documents, such as exporting or updating style definitions.
*   **License Information Display:** View helpful information related to your application installation.
*   **System Compatibility Checker:** Verifies your system meets the necessary requirements for optimal performance.
